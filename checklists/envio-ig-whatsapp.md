# Checklist: envio por Instagram DM / WhatsApp

Antes de cada envio (um por vez):

- [ ] Existe API oficial utilizável (WhatsApp Business Platform / Cloud API, Instagram Messaging API)? Se sim, use-a.
- [ ] O dono aprovou **este arquivo** de vídeo para **este** destinatário.
- [ ] O texto é exatamente um modelo aprovado. Sem preço em mensagem proativa.
- [ ] O canal está liberado para este país/contato (regras locais, pedidos de não contato).
- [ ] Horário comercial do destinatário; abaixo do teto diário; intervalo humano desde o último envio.
- [ ] Sessão já logada na conta certa (não deslogar, não trocar de conta).
- [ ] Idempotência: o vídeo já está na conversa? Então **não reenvie**, só registre.
- [ ] Sem ferramenta de evasão anti-bot (ex.: `undetected-chromedriver`) e sem envio em massa.
- [ ] Apareceu aviso, bloqueio de ação, challenge, captcha ou "atividade incomum"? **Pare** e entregue a um humano.
- [ ] Depois: registre (planilha/board pelo script) e guarde uma prova (um print).
